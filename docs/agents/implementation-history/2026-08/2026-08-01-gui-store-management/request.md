# Feature Request: GUI Store Management

## Original Request

Did our multi-ledger-store feature not include a GUI to manage stores?

We need a full CRUD store management under the configuration screen, in a new tab. Users will typically work more with the GUI as primary tool instead of running commands that you have to look up.

This will also make the default store mechanic more visible and easier to understand. If we add a list of stores with some meaningful details like the kind of information stored in it, it will be a great overview.

What would also be good would be to display the kind of store. Loose folder vs. Git repository storage, for example.
