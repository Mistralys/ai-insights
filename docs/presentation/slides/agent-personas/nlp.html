The Craft of Persona Curation

Natural Language Programming

Writing personas is programming — without code.

The Recipe Curator agent's Workflow — Single Recipe section:

  1. Session Opener — check in, open the ledger, read the request
  2. Choose Culinary Direction — confirm, or default to Discovery
  3. Gather Candidates — produce the brief; no selection yet
  4. Select the Candidate — best fit against the Core Rules
  5. Preview Selection — iterate until the chef confirms
  6. Adapt & Compose — tailor to the household
  7. Format the Output — use the Recipe Format template
  8. Update the Recipe Ledger — append the ID and name
  9. Verify Targets — check nutrition & color coverage
  10. Self-Check — walk the Quality Checklist
  11. Handoff — end with status marker

Same logical structure as a software program. You define inputs, outputs, control flow, and error handling.

This is the key insight for the technical audience: persona curation IS programming. For the non-technical audience: it's a recipe for how the AI should think. You debug personas the same way you debug code — observe the output, trace the logic, adjust the instructions.
