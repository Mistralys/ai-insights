Buffer and question slide. The prompt at the top is there on purpose — "any questions?" tends to get silence, while a concrete question about their own work usually gets someone started. Questions I should be ready for: — What does this cost to run? Be honest: I have not measured it properly. What I can say is which stages get the stronger model and why. — How long does a full workflow run take? Varies with the plan; the honest answer is that the bottleneck is usually the human review stages, not the agents. — Does it work with our internal models? The model registry is the place that answers this — the assignment layer is separate from the personas. — How do you stop it going off the rails? Three answers: the plan is reviewed before any code is written, the pipeline includes QA, security and review stages, and every stage can send work back. — Can I use the personas without the ledger? Yes — that's what the standalone suite is for, and it's the right entry point for anyone starting. — Is this open? Yes, and the Persona Design Guide is already being used by unrelated projects in completely different domains.
